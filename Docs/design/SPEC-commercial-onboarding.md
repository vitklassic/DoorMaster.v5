# DoorMaster — ТЗ (черновик): onboarding компаний и брендинг

Статус: черновик Commercial 2026-11-07, согласован с заказчиком устно. Код не затрагивает.
Связанные документы: [SPEC-commercial-roles](SPEC-commercial-roles.md), [SPEC-commercial-tariffs](SPEC-commercial-tariffs.md), [SPEC-commercial-admin](SPEC-commercial-admin.md).
Пересечение: брендинг совпадает с будущей задачей F1 из ROADMAP — теперь у неё есть коммерческое обоснование.

## 1. Onboarding: как новая компания попадает в сервис

1. Директор (или владелец магазина) устанавливает приложение → «Создать компанию».
2. Вводит: название компании, email, пароль. Загружает логотип компании.
3. Обязательная галочка **согласия на обработку персональных данных** (юридический минимум, утверждён заказчиком).
4. Система автоматически открывает триал 14 дней с полным функционалом.
5. Он создаёт первый магазин и генерирует инвайт-коды (механика инвайтов уже есть в приложении).
6. Менеджеры и монтажники регистрируются по инвайт-кодам.
7. Компания автоматически появляется в панели владельца со статусом «Триал» — ручных действий владельца не требуется.

Правила: одна компания = один email; валюта оплаты на старте — **BYN** (вопрос компаний из других стран отложен).

Альтернатива (не рекомендуется): компании создаёт владелец вручную в своей панели — ручная работа на каждого клиента.

## 2. Брендинг

1. **Логотип компании:**
   - в рабочих экранах приложения (шапка);
   - в печатном PDF-отчёте.
2. **Реквизиты компании** (название, телефон/контакт) — в PDF-отчёте.
3. **Мелкий логотип DoorMaster + контакт владельца сервиса (email)** — внизу каждого PDF.
   - Назначение: вирусный канал привлечения. Замер, показанный в чужом магазине, рекламирует сервис.
   - Важно: PDF остаётся доступен при активной подписке; без подписки PDF заблокирован (см. тарифы) — реклама работает только у платящих.

## 3. Открытые вопросы заказчику

1. Подтвердить автоматическую саморегистрацию компаний (или ручное создание владельцем на старте)?
2. Логотип обязателен или можно без него (текстовое название)?
3. Нужна ли загрузка логотипа при регистрации или можно добавить позже в настройках?
4. Какой контакт владельца сервиса печатать в PDF: email, телефон, сайт?
5. Директор — только просмотр своей сети или добавить ему маленькую вкладку для личных замеров? (заказчик: обдумать)
