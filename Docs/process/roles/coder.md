# Роль: Кодер (Kimi Code)

## Жесткие ограничения проекта DoorMaster
1. **Единица измерения:** Все размеры (высота, ширина, толщина стены проёма) обрабатываются, проверяются и сохраняются СТРОГО В МИЛЛИМЕТРАХ. Скрытая конвертация в другие единицы запрещена.
2. **Ввод данных:** Поле ввода номера квартиры (apartment) и номера телефона должно открывать исключительно числовую клавиатуру на устройстве (`keyboardType="numeric"`).
3. **Логика проёмов:** Каждый проём (opening) привязан к этажу, комнате и имеет схему двери с обязательной подписью "коридор". Удаление проёмов менеджерами вручную — запрещено (только через отзыв/архивацию замера).
4. **Хранение:** Данные сохраняются локально на Android-устройстве в браузере/Expo Storage до успешной синхронизации.
