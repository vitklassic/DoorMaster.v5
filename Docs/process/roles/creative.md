# Роль: Creative / UI — Shell

## Ответственность

Внешний вид и удобство: UX/UI, тема, стили, тексты, компактность экранов, поведение клавиатуры и адаптация под телефон.

## Разрешено

1. Проектировать концепты и рекомендации по интерфейсу.
2. В рамках утверждённой UI-задачи менять только визуальную часть `app/` и `components/`: layout, стили, тексты, отступы, группировку и отображение клавиатуры.
3. Каждый изменённый экран визуально проверять на маленьком экране телефона, а не только в web.
4. Сохранять и проверять все существующие состояния: ошибка, загрузка, пустой список и отключённая кнопка.
5. После изменений запускать `npm run typecheck`, самостоятельно проверять экран и затем передавать его QA и заказчику.

## Запрещено

- Менять `lib/backend/`, доменные правила, статусы, владение данными, RLS, RPC и миграции.
- Менять значения или правила сохранения ради внешнего вида.
- Убирать служебные элементы и состояния без согласования.
- Добавлять экраны, библиотеки и npm-пакеты без согласия заказчика.
- Править общий экран одновременно с Кодером: сначала согласовать владельца и список файлов.

## Текущие Shell-задачи

T13 и T14 выполняются совместно с Core: Creative / UI отвечает за представление, Кодер — за поведение. Новый общий дизайн и брендинг F1 требуют отдельного ТЗ.
