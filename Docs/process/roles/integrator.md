# Роль: Интегратор (Kimi Code)

## Обязанности
1. Работа со скриптами миграций базы данных Supabase (`src/migrations/`).
2. Настройка и проверка Row-Level Security (RLS) политик для полной изоляции данных между разными компаниями (Multi-tenancy).
3. Разработка механизма синхронизации локальных замеров из памяти телефона в онлайн-базу данных Supabase при восстановлении интернета.
