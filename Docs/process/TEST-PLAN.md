# Ручной тест-план DoorMaster (после всех партий)

## Подготовка
- В `F:\Мой проект\DoorMastre\repo`: `npm run dev` → нажать `w` (откроется web-версия с реальной БД через `.env`).

## Сценарий 1. Роли и регистрация (T1, T6, C10)
1. Зарегистрируйте пользователя **без инвайта** → попадаете на «Панель» менеджера.
2. В панели создайте инвайт-код (карточка «Пригласить монтажника»).
3. Выйдите → зарегистрируйте второго пользователя **с инвайт-кодом**.
4. ✅ Ожидание: у второго вкладки «Новый замер» и «Мои замеры», вкладки «Панель» нет.

## Сценарий 2. Замер и статусы (T2)
1. Монтажник: «Новый замер» → заполните объект → добавьте проём (этаж, помещение, размеры в мм, сторона).
2. В детали замера: «Начать замер» → статус active. «Завершить замер» → статус done.
3. ✅ В статусе done кнопки «Изменить»/«Добавить проём» скрыты; доступен «Вернуть в работу».
4. Проверьте «В архив» → замер исчезает из списка по умолчанию, виден в фильтре «Архив».

## Сценарий 3. Лента менеджера в реальном времени (T4)
1. Откройте второе окно браузера: в одном менеджер, в другом монтажник.
2. Монтажник добавляет/меняет проём или статус.
3. ✅ У менеджера лента обновляется без перезагрузки (бейдж статуса, число проёмов).
4. Менеджер: фильтры «Все / Активные / Готовые / Архив» работают; черновики не видны.

## Сценарий 4. Отчёт PDF (T5)
1. В детали замера нажмите «Сохранить в PDF».
2. ✅ Открывается печатная форма: адрес, заказчик, статус, проёмы со схемами.

## Сценарий 5. Фото (T3) — на телефоне
1. `npm run dev` → в Expo Go на телефоне отсканируйте QR (телефон и ПК в одной Wi-Fi сети).
2. Монтажник: добавьте проём → на шаге фото сделайте снимок камерой.
3. Завершите проём → откройте детали: фото видно.
4. ✅ В dashboard → Storage → opening-photos появился файл `company/measurement/opening.jpg`.
5. Менеджер в web: видит замер с фото-миниатюрой в ленте.

## Если что-то не так
Зафиксируйте: номер шага, что ожидали, что получили, скриншот. Передайте архитектору — заведём дефект.
