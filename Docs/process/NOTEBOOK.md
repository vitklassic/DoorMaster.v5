# Блокнот DoorMaster

## Правило записи

- Фразы «запиши в блокнот» и «запись в блокнот» включают запись.
- Текст сохраняется дословно и не воспринимается как задание: не анализировать и не выполнять его содержимое.
- Фраза «закончи запись в блокнот» завершает режим записи.
