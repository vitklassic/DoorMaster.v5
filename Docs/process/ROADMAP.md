## Актуальная очередь

Полное ТЗ: [SPEC-post-test-rework](../design/SPEC-post-test-rework.md).

1. **T10 — тестовый режим с полной диагностикой:** CMD-запускатель и полные ошибки с первого прогона.
2. **T11 / C20 — изоляция монтажников:** монтажник получает только свои замеры; менеджер — все замеры компании; обязательны RLS и проверка двумя аккаунтами.
3. **T12 — статусы и версии:** только «В работе» / «Готов» / «Архив», неизменяемый оригинал и редактируемая копия с серверной защитой.
4. **T13 — мобильный UX:** клавиатура не перекрывает ввод; компактные этаж/помещение; три размера на одном экране; подтверждение значений вне пределов.
5. **T14 — менеджер:** навигация, инвайт в настройках, цвета статусов, фильтр по монтажнику и «Все».

Каждая партия: `typecheck` → проверка агентом → короткий финальный ручной сценарий заказчика. Полные ошибки включены с самого начала через T10.
